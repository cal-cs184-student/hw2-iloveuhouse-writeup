Section I: Bezier Curves and Surfaces

Part 1: Bezier curves with 1D de Casteljau subdivision

Bezier Curves
Bezier curves are parametric curves that are used to represent smooth curves and surfaces in computer graphics. They are defined by a set of control points, and each point on the curve is a linear combination of these points. De Casteljau's algorithm is one way to evaluate them.

De Casteljau's algorithm
De Casteljau's algorithm evaluates a point on a Bezier curve using repeated linear interpolation. In one step, it takes the current set of points and replaces it with a new set, which has one fewer point. Each new point is the linear interpolation between a pair of adjacent points, all using the same parameter \(t\). This process is repeated until we reach a single final point, which is the point on the Bezier curve at \(t\). As a more detailed description of the implementation, we use a lerp function defined as follows: Given n+1 control points \(P_0, P_1, \ldots, P_n\) and a parameter \(t\) in the range [0, 1], the linear interpolation between two points \(P_i\) and \(P_{i+1}\) is given by: \[ \text{lerp}(P_i, P_{i+1}, t) = (1 - t) \cdot P_i + t \cdot P_{i+1}. \] Each call to our evaluateStep function applies lerp to every pair of adjacent points and returns the next set of n points, and we repeat this process (\(n+1 \to n \to \cdots \to 1\) points) until we reach the final single point.
